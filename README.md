# SDS Redis Kit: CompUni

A starter repository for the [SDS WebSocket Guide](https://github.com/sds-edu/SDS-Websocket-Guide). This project implements a real-time Chat Application using Node.js, Express, and React.

## Quick Start

1. **Install dependencies:**

    ```bash
    npm install
    ```

2. **Run the server:**

    ```bash
    npm run dev
    ```

3. **Open the app:**
    Visit <http://localhost:5173> in your browser.

## Project Structure

- `server/server.js`: Main Express application with Redis integration placeholders.
- `client/`: Frontend files.

## Instructions

Follow the step-by-step instructions in the [official guide](https://github.com/sds-edu/SDS-Websocket-Guide) to implement the missing logic and complete the application.
